# User guide

How players and staff of Atletico San Lorenzo use the app.

> **Source**: the web app of this repository
> **Last update**: 2026-11-20 · **Scope**: usage of the web app · **Markers**: none

Each OpenSpec change that adds a feature adds its page here.

| Section | Contents | Read when |
|---|---|---|
| [login](login.md) | Sign in, lockout, session, sign out, forgotten password | You want to enter or leave the app |
| [invite-links](invite-links.md) | Create an account or a new password through a link; add players and create links as an admin | You received a link, or you are an admin |
| [profile](profile.md) | Your data, change your name | You want to see or change your own data |
| [users](users.md) | Roles, list the accounts, change a role, keep one admin | You are an admin |
| [navigation](navigation.md) | Sections, Home panels, theme, sidebar on a wide screen, drawer on a phone | You want to move between sections of the app |
